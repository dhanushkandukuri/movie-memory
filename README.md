# Movie Memory

Sign in with Google, save your favorite movie, and get a fun fact about it.

Built with Next.js (App Router), TypeScript, Tailwind CSS, Postgres + Prisma, Auth.js (Google OAuth) and the OpenAI API.

> Work in progress. Full setup instructions and architecture notes will be added here.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
